How Meal Rules Work

Rules tell the app which recipes to pick for each meal slot. Rules are evaluated in order — higher priority rules (lower sort order) are tried first. A rule matches a day and meal type, then picks a recipe with matching tags (or any recipe if no tags specified). Manual overrides are respected — generated entries are not overwritten.

Example Rules for a 2-Week Plan
  • Weekday dinner → tag "standard" — Two-night recipes like roast chicken, stir fry
  • Friday dinner → tag "friday-special" — Treat meals, single night
  • Saturday & Sunday breakfast → tag "breakfast" — Weekend breakfast options
  • Weekday lunch → any recipe — Whatever you have tagged
